# Git Tutorial

```sh
# 깃 초기화
git init

# 스테이징에 추가
git add .
git add -A
 
```

```bash
# commit
git commit -m "commit message

```

```bash
# push command
git push origin main

```

```sh
# git 로그 명령어

git log
git log --oneline
git log --oneline --all

```

### 브랜치 생성 및 스위치

```sh
git branch [branch_name] : 브랜치 생성
git checkout [branch_name] : 브랜치 이동

git checkout -b [branch_name] : 브랜치를 생성하고 해당 브랜치로 이동

```
